                About this project

                I built this from my Spotify Extended Streaming History export. A Python script (build-dashboard.py) reads the raw files, converts every timestamp to local time, and boils the data down to totals by song and month, so no individual plays, IP addresses or devices are published. A play counts once it reaches 30 seconds, the same rule Spotify uses. Genres, release dates and sound details (energy, positivity, tempo, loudness) come from exports of my playlists. Each song gets a mood from two scores: intensity, which mixes energy, tempo and loudness, and positivity. Fast, loud songs score as Hyped or Intense, and slower, softer ones as Chill or Moody, depending on how positive they sound. Charts are drawn with Chart.js. The code is on GitHub.

      About this project

      I built this from my Spotify Extended Streaming History export. A Python script (build-dashboard.py) reads the raw files, converts every timestamp to local time, and boils the data down to totals by song and month, so no individual plays, IP addresses or devices are published. A play counts once it reaches 30 seconds, the same rule Spotify uses. Charts are drawn with Chart.js. The code is on GitHub.
